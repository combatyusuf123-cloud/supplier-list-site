Register a supplier once. Select every product category they supply so they appear in all relevant sections.

PostgreSQL database

Every supplier is stored in your PostgreSQL database and this page reads and writes it live. The connection string lives in the server's .env file (DATABASE_URL) — nothing to configure here.
If the connection fails, click Test connection for the exact error. The suppliers table is created automatically when the server starts with a valid DATABASE_URL.
